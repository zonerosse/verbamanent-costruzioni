# Verba Manent IA e Scripta Manent – costruzioni

Qui girano solo le **costruzioni** e le **prove** dei programmi (Windows, Android, iPhone, Mac).
Il codice non è qui: ogni costruzione lo prende dal progetto privato con una chiave segreta,
e i risultati delle prove tornano nel progetto privato.

I file in `.github/workflows` si rifanno con `tools/costruzioni_pubbliche.py` del progetto privato:
non cambiarli a mano.

I programmi si scaricano da https://verbamanent.app
